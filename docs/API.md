# API Reference — islamic-astro-java

## Classes
- `PrayerTimesCalculator.calculate(...)`: Thread-safe calculation of solar times.
- `QiblaCalculator.calculate(lat, lng)`: Great-Circle bearing and distance to Kaaba.
- `PrayerTimes`: Record holding Fajr, Sunrise, Dhuhr, Asr, Maghrib, Isha ZonedDateTimes.
- `CalculationMethod`: Enum representing MWL, ISNA, Egypt, Makkah, Karachi, Tehran, Jafari.
